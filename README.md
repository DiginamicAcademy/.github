# Diginamic Academy

Cette organisation regroupe les dépôts des cours de Diginamic.

Chaque cours est disponible sous plusieurs formes : 
- cours en format Markdown + PDF
- slides en format Marp + PPTX & PDF en fond clair et sombre

Chaque cours et journalisé et régulièrement mis à jour.

Chaque auteur·ice est crédité·e, de même que chaque contributeur·ice.
